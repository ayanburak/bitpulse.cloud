# Security

The whole code of Bitpulse is public, so the safety of the site must never depend on the code staying secret. Keys, access rights and separated services protect it instead.

## Reporting a problem

A security problem is reported privately through the Report a vulnerability button on the Security tab of this repository. A private report keeps the problem out of public view until it is fixed, which is why public issues are not used for this.

A useful report names the affected page or file and gives the steps that show the problem. Reports are read as soon as possible.

## Scope

The code in this repository and the live site at bitpulse.cloud are in scope. Testing stops at the point where the problem is shown. Denial of service, spam, social engineering and access to data that belongs to someone else are not allowed.
